# AI-Assisted-Development
Document the journey of mine

## Motivation
I first get in touch with generative AI in mid 2025. At that time we used it for information gathering, code completeion or for generating small fragments at most.
Now at the end of 2026 I delegate most of my coding to agents and I constantly experimenting building an effective ecosystem that produce high quality application code consistently.
The main motivation of this project is to document the ongoing journey. It might be fun to look back, and I hope it will be beneficial for me and for others to review the concepts and decisions I made.
