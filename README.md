# AI-Assisted-Development
Document the journey of mine

## Motivation
I first get in touch with generative AI in mid 2025. At that time we used it for information gathering, code completeion or for generating small fragments at most.
Now at the end of 2026 I delegate most of my coding to agents and I constantly experimenting building an effective ecosystem that produce high quality application code consistently.
The main motivation of this project is to document the ongoing journey. It might be fun to look back, and I hope it will be beneficial for me and for others to review the concepts and decisions I made.

## Evolutionary steps
(Evolution is "not a principle of progress; it's just a principle of local adaptation". /Stephen Jay Gould/)
### The old way - for me at least
- Code completion with IntelliSense and so
### Dawn of AI in my career
- Code completion with generative AI
- AI assisted search and information gathering
- Generating code snippets
### AI aided discovery
- Understand problems (grill-me)
- Generating mockups
- Prototyping
- Planning (writing-plan)
### AI driven implementation
- Start shaping guidelines with profile instructions (~/.codex/AGENTS.md)

### Software Factory
- Experimenting with orchestration
- First tailored agent
- Extending team-defined project-level guidelines with personal ones (<PROJECT_DIR>/.codex/AGENTS.md)

- Tweaking agents with "personality" traits (a developer inspired by Linus Tolvards and an architect inspired by Uncle Bob)
